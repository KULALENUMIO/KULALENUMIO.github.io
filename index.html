はじめに

GitHub に置いている道具の案内ページです。リポジトリが増えて分かりにくくなったので、何がどこにあって、何に使うのかをここにまとめました。

This page lists the tools on github.com/KULALENUMIO: the SMC-AD series (Scrap Mechanic blueprints → Blender → Unity HDRP) and a few game mods. Most READMEs are in Japanese; Blueprint Lib and the Sprocket mod also have English ones.

⚠ ご注意　SMC-AD シリーズ（SMC-AD・Surfaces・Importer・SMC-DETAILS・Tank Rigging）はα版・試作品です。作者の気まぐれで作っているので、まともな更新やサポートは期待しないでください。使い方やデータの形式は予告なく変わります。

SMC-AD シリーズ

SMC-AD（Scrap Mechanic Converter – Assemble & Deliver）は、Scrap Mechanic で作った機体を Blender で整え、Unity（HDRP）に持っていくか Blender で撮影するための道具一式です。下の 5 つと変換ツールでできています。Unity 側は HDRP 専用です（URP 版の配布は終わりました）。

  • Blender で撮影するだけなら、Unity 側は要りません
  • SMC-DETAILS と Tank Rigging は、どちらも入れなくても、片方だけでも使えます。両方入れると、作業ビュー（車両だけを映す別ウィンドウ）は共通の 1 つになります
SMC-AD（Blender 拡張＋変換ツール） ― 0.7.0 ／ リリース v0.7.0-alpha（2026/11/24）

ブループリントを選ぶだけで、変換して Blender に取り込みます。部品の位置・回転・原点・親子を整え、Unity 向けに書き出します（リギングは手作業）。

  • 変換と取り込み（ジョイントごとにボディを分ける、見えない面を消す など）
  • SM の見た目のマテリアル、色の差し替え、ボディの親子の整理
  • 左右反転コピー（先の部品も）、量産向けのアトラス書き出し（試作）
  • Unity 向けの FBX 書き出し

必要なもの: Windows、Scrap Mechanic（変換にゲームのデータを使います）、Blender 4.2 以降（確認は 5.3）

入れ方:

  1. 変換ツールの zip を好きな場所に展開する
  2. Blender の「編集 ＞ プリファレンス ＞ 拡張機能 ＞ ディスクからインストール」で smc_ad-0.7.0.zip を入れる
  3. SMC-AD の設定の「変換ツール（SMConverterCLI.exe）」に、展開したフォルダの SMConverterCLI.exe を指定する
  4. サイドバーの「SMC-AD」タブ →「ブループリントから取り込む…」

▼ 変換ツール（5 MB） ▼ smc_ad-0.7.0.zip リリースのページ リポジトリ

変換ツールが起動しないときは、Microsoft Visual C++ 再頒布可能パッケージ（x64）を入れてください。

SMC-AD Surfaces（Blender 拡張・任意） ― 0.4.0

パーツごとに材質（金属・ゴム・木など）を付けます。設定は Unity に書き出しても引き継がれます。パネルは同じ「SMC-AD」タブの中、SMC-AD の下に出ます。

入れ方: SMC-AD と同じく「ディスクからインストール」で smc_ad_surfaces-0.4.0.zip。以前の「SMC-AD+ Surfaces」は先に削除してください（自分で保存した味付けは自動で引き継ぎます）。

▼ smc_ad_surfaces-0.4.0.zip

SMC-AD Importer for Unity ― com.smcad.importer 0.5.0

Blender から書き出した FBX（または変換ツールの .glb）を、Scrap Mechanic の見た目（塗装色・光沢・発光・ガラス）のまま Unity に取り込みます。シェーダーは HDRP の Shader Graph です。Blender で付けた色や材質も引き継ぎます。

必要なもの: Unity 6000.3 以降、HDRP 17.3 以降（リニア色空間）

入れ方: Package Manager の「＋ ＞ Add package from tarball…」で tgz を入れる（tgz は入れたあとも消さずに置いておく）。Tools ＞ SMC-AD から取り込みます。

URP で作ったマテリアルは Tools ＞ SMC-AD ＞ URP のマテリアルを HDRP に変換 で移せます。

▼ com.smcad.importer-0.5.0.tgz

SMC-DETAILS for Unity（試作・任意） ― com.smcad.details 0.4.0

取り込んだ機体を汚したり、装備を付けたりします。焼き込みはなく、スライダーを動かすとすぐ見た目に反映されます。

  • 汚し: 塗装の質感、傷、錆、泥、砂 など
  • 手描きブラシ、デカール
  • 装備: チェーン、カモネット、布（揺れ・風あり）

入れ方: Importer を入れたあと、同じく tarball で入れます。Tools ＞ SMC-AD ＞ 汚し・装備（SMC-DETAILS）

▼ com.smcad.details-0.4.0.tgz

SMC-AD Tank Rigging for Unity ― com.smcad.tankrig 0.9.0-alpha（2026/11/24）

Unity に取り込んだ戦車を、WASD とマウスで操縦できる戦車にします。組み立てウィンドウで車体・砲塔・砲身を選び、履帯を置いて、ワンクリックで組み立てます。

  • 車体の物理演算と転輪ごとのサスペンション、地形に沿う履帯、地面に残る轍
  • War Thunder 風のカメラと操作、主砲・機銃・副砲塔
  • 照準器 3 種類（光学、疑似サーマル、全周ゴーグル）、レーザー測距、弾種の選択
  • 発砲炎・主砲の爆風・排気・土煙などのエフェクト、ターレットリングの疑似内装

必要なもの: Unity 6000.3 以降＋HDRP 17.3 以降、Input System（自動で入ります）、Importer で取り込んだ戦車

入れ方: Package Manager の「＋ ＞ Add package from git URL…」に次を入力します（Git LFS が必要です。ない場合は下の tgz を tarball で）。

https://github.com/KULALENUMIO/SMC-AD-TankRigging.git?path=/com.smcad.tankrig#v0.9.0-alpha

Tools ＞ SMC-AD ＞ 戦車（Tank Rigging） ＞ 戦車組み立てウィンドウ から使います。先にプロジェクトのバックアップを取ってください。

Scrap Mechanic の MOD

Blueprint Lib ― 1.0.1（2026/11/15）

クリエイティブ向けの、リフトの代わりになるブループリント管理ツールです。何百個もあるブループリントを、フォルダ・タグ・お気に入りで整理して、リフトのように設置できます。ゲームを起動しなくても、ブラウザの管理画面で整理できます。

  • フォルダ（階層あり）・タグ・お気に入り・非表示・最近使った、検索と並び替え
  • まとめて移動・タグ付け・順に設置
  • 足りない MOD があるブループリントには ⚠ を表示
  • 元の Blueprints フォルダは読むだけで、書き換えません。英・日・韓・中の 4 言語

必要なもの: Scrap Mechanic（クリエイティブのみ）、Python 3.10 以降（管理画面と一覧の作成に使います）

Steam Workshop で購読 ▼ zip（Workshop を使わない場合） リポジトリ

そのほかの MOD

Sprocket Arcade Battle MOD ― 1.12.0（2026/11/19）

Sprocket の戦車戦を、War Thunder や World of Tanks のようなアーケード風にする MOD です。機能はどれも、ゲームの設定画面に増える「MODS」タブで切り替えられます。

  • 弾道の予測と、着弾点での貫通判定（色で表示）
  • ギアや回転数を気にしなくていい操縦、素早い砲塔
  • 右クリックでズーム／キューポラ視点、弾種の切り替え（1・2・3）
  • 砲の名前に [AC 10/450] と書くと機関砲になる、撃破ログ、ミニマップ、修理 など

必要なもの: Sprocket 0.2.56.3、BepInEx 6.0.0-be.788（IL2CPP・Windows x64）。ゲームの更新で動かなくなることがあります。

どれを入れる？

やりたいこと入れるもの
SM の機体を Blender で撮影したい変換ツール ＋ SMC-AD（材質も付けるなら ＋ Surfaces）
SM の機体を Unity に持っていきたい上のもの ＋ Importer for Unity
Unity で汚したり、装備を付けたい上のもの ＋ SMC-DETAILS
Unity で戦車を走らせたいImporter まで ＋ Tank Rigging
SM のブループリントを整理したいBlueprint Lib だけ
Sprocket をアーケード風に遊びたいSprocket Arcade Battle MOD だけ
